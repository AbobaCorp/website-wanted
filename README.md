# 🕵️ Разыскивается: Ленивый Пельмень

Шуточный «розыскной» постер в виде одностраничного сайта.  
Посвящён Руслану (по кличке «Ленивый Пельмень»), который систематически игнорирует пары.

## О проекте

Сайт стилизован под старый бумажный объявление о розыске:

- Заголовок **РАЗЫСКИВАЕТСЯ**
- Фото «преступника» с сепия-фильтром
- Приметы и список обвинений
- Награда: **ШАВУХА ЗА НАШ СЧЁТ**
- Кнопка «Я готов вернуться» с случайными мотивирующими сообщениями
- Печать «ЖДЁМ НА ПАРАХ»

Всё сделано чисто на HTML + CSS (без фреймворков) + немного ванильного JavaScript.

## Структура

```
website-wanted
├── README.md
├── index.html
├── photo.png
└── style.css
```

## Как запустить

Просто открой `index.html` в любом современном браузере — никаких серверов и сборок не требуется.

## Кастомизация

- **Фото** — замени `photo.png` на своё (рекомендуемое соотношение 3:4).  
  Если файла нет, появится заглушка «[фото уточняется]».
- **Тексты** — правь прямо в `index.html`.
- **Цвета** — все основные переменные находятся в начале `style.css`:

```css
:root {
  --paper: #e8d9b5;  /* цвет бумаги */
  --ink:   #2b1d0e;  /* цвет чернил */
  --red:   #9b1c1c;  /* акцентный красный */
  --wood:  #3a2616;  /* фон вокруг постера */
}
```
